# Student Portal Frontend

This is the frontend application for the Student Portal of the GPSD Class Management System. The original project design is available at [Figma](https://www.figma.com/design/fBVXEwyysHJfNi9jIXmZ5Y/Student-Portal-Frontend-Design).

## Features
- **Student Dashboard:** Overview of recent activities and notifications.
- **Materials & Notes:** Access to lesson PDFs and secure video streams.
- **Performance:** View examination marks and progress.

## Running the code
1. Run `npm i` to install the dependencies.
2. Run `npm run dev` to start the development server (runs on port 5174).
