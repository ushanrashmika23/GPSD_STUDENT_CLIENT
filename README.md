
  # Student Portal Frontend - Learning Management System (LMS)

Welcome to the frontend repository for the **Student Portal**, a modern, responsive user interface designed specifically for an Advanced Level Combined Mathematics tuition class learning management system. This application provides a seamless, intuitive dashboard for students to manage their academic activities, view course materials, and track progress.

---

## 🚀 Features

*   **Interactive Student Dashboard:** Overview of schedules, announcements, and recent activities.
*   **Course Management:** Easy navigation through Combined Mathematics modules and lessons.
*   **Modern UI/UX:** Styled using a sleek, dark-themed interface built for readability and focus.
*   **Highly Responsive:** Fully optimized for both desktop and mobile layouts.

---

## 🛠️ Tech Stack & Architecture

This client application is built with modern web development tools ensuring speed, modularity, and type safety:

*   **Framework:** React with [Vite](https://vitejs.dev/) (for lightning-fast development and building)
*   **Language:** [TypeScript](https://www.typescriptlang.org/) (ensuring robust type safety)
*   **Styling & UI Components:** [Tailwind CSS](https://tailwindcss.com/) & [shadcn/ui](https://ui.shadcn.com/)
*   **Package Management:** Monorepo capability structured via `pnpm-workspace.yaml`.
